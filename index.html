Software

HomotopyGetsReal.jl

Code · Documentation

A native Julia reimplementation of the Bertini_real decomposition pipeline: it decomposes real algebraic curves and surfaces into vertices, edges, and faces using HomotopyContinuation.jl, with no witness-set stage and no C dependency. Includes generic projection and isosingular deflation. Registered in the Julia General registry (v0.2.1, MIT license).

M2Bridge.jl

Code

Prototype of a persistent Julia interface to Macaulay2: keep one M2 subprocess alive and exchange code and results as native Julia values across many calls. Inspired by m2r (R) and sage.interfaces.macaulay2 (Python).

Combinatorial Burnside groups

Code

Julia/OSCAR implementation of the combinatorial Burnside groups BCn(G) of Tschinkel–Yang–Zhang (arXiv:2112.12801). Reproduces all 52 published values we could locate; 88/88 validation checks pass.

LPPCheck.jl

Code

Computational stress test, in exact arithmetic with Oscar.jl, of the Eisenbud–Green–Harris and lex-plus-powers statements (Hilbert functions and graded Betti numbers). Computational evidence only, not a proof.

Meshfree GFDM on algebraic varieties

Code

Meshfree generalized finite difference method for elliptic PDEs on curved and singular algebraic varieties, using local tangential parameterization and homotopy continuation to locate singularities and tangent cones.

Earlier work: Resolviendo ecuaciones polinomiales (Julia/Oscar code from my undergraduate thesis on solving polynomial systems). Forks of bertini_real and HomotopyContinuation.jl are also on my GitHub.
